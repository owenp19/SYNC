SYNC API

Backend en Laravel 13 · Autenticación por token Bearer (Sanctum) · Control de piso de voz con heartbeat de 300s · E2EE en LiveKit.

● http://localhost:8000/api

Autenticación

Obtén un token con POST /api/auth/login y envíalo en cada petición:

Authorization: Bearer {token}
POST/auth/login

Inicia sesión y devuelve un token Bearer junto con el usuario.

Body

CampoTipoDescripción
emailstring (email)Correo del usuario
passwordstringContraseña

Respuesta 200

{
  "token": "1|abc123...",
  "user": { "id": 1, "name": "Recepción", "email": "recepcion@sync.local", "status": "available" }
}

Errores

401 Credenciales inválidas · 422 Datos inválidos

POST/auth/logout

Revoca el token de acceso actual. Requiere Authorization: Bearer.

Respuesta 200

{ "message": "Sesión cerrada" }
GET/auth/me

Devuelve el usuario asociado al Bearer token actual (usado por los guards de la app).

Respuesta 200

{ "id": 9, "name": "Owen", "email": "owen@sync.com", "status": "available" }
POST/voice/token

Genera un JWT de LiveKit para unirse a la sala del canal indicado. Devuelve la clave E2EE por canal y el nombre del usuario.

Body

CampoTipoDescripción
channel_idintegerID del canal
guest_idstringID del dispositivo (opcional)
departmentstringDepartamento elegido (opcional)

Respuesta 200

{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "url": "http://localhost:7880",
  "e2ee_key": "15de64cf...",
  "user_name": "Equipo Seguridad"
}

Errores

401 Sin token · 403 Sin acceso al canal · 422 Datos inválidos

POST/channels/{channel}/floor/acquire

Solicita el piso de voz del canal. Si está ocupado responde 409. El piso expira a los 300s sin heartbeat.

Respuesta 200

{ "granted": true, "message": "Canal disponible. Puede transmitir." }

Error 409

{ "granted": false, "message": "Canal ocupado." }
POST/channels/{channel}/floor/release

Libera el canal si eres el ocupante actual.

Respuesta 200

{ "message": "Canal libre." }
POST/channels/{channel}/floor/heartbeat

Extiende floor_expires_at en 300s mientras sigas ocupando el canal. Envíalo cada 60s.

Respuesta 200

{ "message": "ok" }

Error 409

{ "message": "No posees el piso de este canal." }
GET/events

Últimos 20 eventos de audio (floor_acquired, released, denied, floor_expired).

Respuesta 200

[{ "id": 5, "event": "floor_acquired", "user_name": "Equipo Seguridad", "channel_name": "Recepción", "created_at": "..." }]
GET/admin/users

Lista usuarios con su departamento asignado.

Respuesta 200

[{ "id": 3, "name": "Equipo Recepción", "email": "...", "department_id": 1, "department_name": "Recepción" }]
GET/admin/departments

Lista los departamentos del hotel.

Respuesta 200

[{ "id": 1, "name": "Recepción", "channel_id": 1 }]
PATCH/admin/users/{user}/department

Asigna un departamento al usuario.

Body

CampoTipoDescripción
department_idinteger|nullID del departamento (null = sin depto)

Respuesta 200

{ "id": 3, "name": "Equipo Recepción", "department_id": 1, "department": { "name": "Recepción" } }
